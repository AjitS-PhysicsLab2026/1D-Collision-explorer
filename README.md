# ⚽ Ajit's Collision Simulation Lab

An interactive, real-time physics simulation laboratory built using **Python**, **Streamlit**, and **HTML5 Canvas script mechanics**. 

## 🌟 Features
- **1D Horizontal Collision:** Simulate elastic and inelastic impacts between two dynamic bodies with mass, initial velocities (including negative vector directions), and coefficient of restitution controls.
- **Vertical Free Fall & Bounce:** Track a sphere dropping from precise metric heights. Supports user-defined custom bounce targets, structural height marker line indicators, zero-drift absolute rest floor states, and dynamic visual object squeeze-stretching.

## 🚀 How to Run Locally
1. Clone this repository.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Boot up the Streamlit host server:
   ```bash
   streamlit run app.py
   ```
